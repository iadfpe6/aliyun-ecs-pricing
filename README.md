## 新用户、老用户与同人账号：活动规则里最容易踩的坑

云小站的商品分三类：秒杀产品、新用户专享产品、新老用户同享产品，大部分纠纷都出在“新用户”的认定上。官方规则里的定义是：在阿里云官网没有收费云产品购买记录的会员用户。注意“云产品”指国内节点（不含香港）的产品和服务，不含域名、虚拟主机和云市场商品——也就是说，只买过域名不算老用户，照样能拿新客价。

几个容易踩的具体点：

1. **同人账号会被合并判定。** 官方按同一证件、同一手机号、同一支付账号、同一设备、同一地址等关联信息判断“同一用户”。换个手机号重新注册一个账号去领新客价，大概率会被识别为同人账号，资格不互通。
2. **新用户专享同一用户生命周期内只能买1次**，活动优惠限1单1件，买过一次这个账号就再也没有首购价了。
3. **秒杀产品看的是品类购买记录**，之前没买过该类产品就能参与，库存每天上午10点更新。
4. **老用户也有专属口子**：ECS老用户可以在“爆款产品5折起”专区按优惠价购买，限1单、每单上限3台。

退款是另一个大坑。活动产品除特殊情况外不支持退订，确因特殊原因退订的，要先交回通过活动享受的权益，比如补足差价、退还已使用的代金券。新老同享专区的OSS产品无法申请线上退款。所以别抱着“先买了不合适再退”的心态下单。
